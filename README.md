# 作品集網站

單一 `index.html` 的一頁式作品集，以 GitHub Pages 發布。頁面上的作品皆為**示範作品**。

## 待填項目

- `[稱呼]`、`[一句話介紹]`：在 `index.html` 搜尋這兩個字串替換。
- 社群貼文圖片：放進 `images/`，把 `<div class="slot">圖片 1<br>待補</div>` 換成
  `<div class="slot"><img src="images/檔名.jpg" alt="貼文說明"></div>`。
- 桂花冷萃文案連結：把 `<span class="todo">連結待補</span>` 換成 `<a href="網址">閱讀文案 →</a>`。
